Rows marked "v3:" are the plan 10 (v3.0.0) assets in `public/assets/v3/`
(manifest: `public/assets/v3/manifest.json`). Third-party v3 assets are fetched
and processed by `scripts/fetch-v3-assets.mjs`, which checks each source site's
CC0 licence page before downloading; own-work v3 assets are generated by
`scripts/build-v3-own-assets.mjs`; `scripts/check-v3-assets.mjs` verifies that
every v3 file has a row here. The v2 rows above stay until the v3 build stops
loading those files.

Everything else — species models, terrain, textures, the v2 stream water,
dry-stone wall, gate, hills, butterflies, mist, cloud shadows and the
field-ecologist character (procedural, `src/v2/` + `src/scenes/meadow.js`),
sounds-free design, charts —
is original procedural work in this repository (MIT), constructed for teaching
purposes. Species are fictional and botanically plausible; field marks are
slightly exaggerated for legibility (see `design/realism-matrix.md`).
