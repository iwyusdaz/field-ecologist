# Human playtest protocol (stubs — for the first real sessions)

No real learners have tested this project yet. These short templates are ready
for the first sessions; nothing here has been run.

## 1. Consent script (classroom / individual)

> "You're going to try a field-sampling simulation we built for teaching. It
> saves what you click only inside this browser — nothing is sent anywhere.
> You can leave any time. May we note down what you do and say to improve the
> exercise? Your notes are anonymized and you can ask us to delete them."

Minors: teacher/parent consent per school policy; record only anonymized notes.

## 2. Session template (45–60 min)

- 0–5 min: think-aloud setup ("say what you're thinking"), pre-check items as
  spoken questions.
- 5–15 min: Module 1 + 2 (hypothesis, field guide, ID quiz). Note: any field
  marks that don't make sense without the 3D view.
- 15–35 min: Module 3 fieldwork. Record: design choice + stated reason, any
  confusion in the counting view, whether the time meter is understood, count
  entry errors.
- 35–45 min: Module 4 reveal + simulator. Ask before revealing: "how close do
  you think you are?" Then after: "what does the spread mean? what would more
  quadrats change?"
- 45–55 min: Module 5 transfer items + report self-check. Ask the transfer
  question in the learner's own words afterwards.
- Debrief: one thing that helped, one thing that confused you.

## 3. Observation sheet fields

- Participant code, date, mode (3D / text), preset (auto-selected)
- Design chosen + stated reason
- Pre/ID/transfer item answers (from the local record download, with consent)
- Confusion points (timestamp + note)
- Reveal reaction (what they think the error means)
- Anything the text mode made harder/easier

## 4. After the session

- Export the local record (My progress → Download as JSON) with consent; strip
  timestamps if anonymity is requested.
- File findings as issues; update items/copy; note changes in CHANGELOG.
